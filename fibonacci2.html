Фибоначчи сандары

1, 1, 2, 3, 5, 8, 13, 21, 34 … — табиғаттағы, өнердегі және бағдарламалаудағы «құпия» тізбек.

Төменгі «Келесі» батырмасын немесе → пернесін басыңыз.

1-бөлім

Кім ойлап тапты?

Италиялық математик Леонардо Пизанский (Фибоначчи) 1202 жылы «Liber Abaci» кітабында қояндардың көбею есебін қойды.

Есеп: бір жұп қоян бір айдан кейін ересек болады, содан соң әр айда бір жаңа жұп туады. Жаңа туған жұп те осылай көбейеді. Бір жылда неше жұп болады?

Жауап — тізбектің мүшелері: 1, 1, 2, 3, 5, 8 …

4-бөлім

Алтын қима φ ≈ 1,618

Көрші сандардың қатынасы Fₙ₊₁ / Fₙ жүгірткіні жылжытқанда алтын қимаға жақындайды.

φ = (1 + √5) / 2 ≈ 1,6180339887

7-бөлім

Күнделікті мысал: миля → км

Көрші екі Фибоначчи саны миляны километрге ауыстыруға көмектеседі: F(n) миля ≈ F(n+1) км.

Себебі: 1 миля ≈ 1,609 км, ал 1,609 ≈ φ. Сондықтан Fₙ₊₁/Fₙ қатынасы осы санға өте жақын.

13-бөлім

Өнер, музыка, сәулет 🎹

14-бөлім

Тиімді алгоритм: мемоизация

memo = {0: 0, 1: 1}

def fib(n):
    if n not in memo:
        memo[n] = fib(n-1) + fib(n-2)
    return memo[n]
